# Will cheaper software commoditize advantage or deepen scale moats?

## Central question

When AI makes software and model output cheaper, does value disperse through commoditization and new entry, or concentrate around actors that can finance scale and own scarce complements?

## Position A

**Cheaper production erodes software moats.** If code and model capability become commodity layers, the cost of creating software can no longer justify SaaS margins or secure a durable proprietary position. A breakthrough client can catalyze a market without becoming its lasting titan.

## Position B

**Scale becomes the moat.** If better performance requires larger models, inference budgets, GPUs, capital, and distribution, value can accrue to a small set of firms even while application code becomes cheap.

## Additional positions

- Open model releases can weaken model-layer concentration while shifting advantage to integration, data, workflow, or distribution.
- Transformative technology can create social value while producing poor or highly unequal investor returns.
- New use cases may expand the market enough for both commodity infrastructure and differentiated systems to coexist.

## Sources of disagreement

- Which layer is being priced: model, application, workflow, or distribution.
- Whether model scaling continues to yield proportional utility.
- Availability of open models, compute, capital, and interoperable infrastructure.
- The difference between falling production cost and falling customer switching cost.
- Timeframe: temporary boom rents versus mature industry structure.

## Current assessment

The dispute is not resolved at one level. Software production can commoditize while compute, distribution, proprietary context, or organizational integration concentrate. The key empirical task is to identify where the bottleneck—and therefore the rent—moves.

## Open questions

- Which complements remain scarce after code generation becomes abundant?
- Do open models reduce concentration or primarily lower application-layer entry costs?
- How quickly do cost reductions translate into lower prices rather than higher margins?
