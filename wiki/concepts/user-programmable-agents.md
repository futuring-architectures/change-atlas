# User-programmable agents

## Definition

A user-programmable agent exposes enough of its persistent instructions, context, permitted tools, review policy, and learning loop for a user or community to shape how it acts on their behalf.

## Significance

The concept reverses the conventional application boundary: developers provide a safe domain and tools, while users participate in specifying the general behavior. That can return agency to domain practitioners, but it can also transfer security, maintenance, and accountability burdens to them.

## Boundary

An editable prompt is not sufficient. Meaningful programmability requires legible state, reversibility, tests, permission boundaries, portability, and recourse when an agent causes harm.
