# Contextual defensibility

## Definition

Contextual defensibility is advantage rooted in a situated understanding of the problem: which distinctions matter, what data model expresses them, which exceptions are legitimate, what good looks like, and which tradeoffs a product repeatedly chooses.

## Mechanism

When shared models make generic implementation cheaper, technical access diffuses faster than domain judgment. Context becomes defensible only when embedded in data, workflows, relationships, evaluation, and decision rights—not when hired as a decorative advisory layer.

## Boundary

Context is not automatically proprietary or correct. Insiders can inherit stale frames; outsiders can see neglected possibilities. Defensibility must remain open to counterevidence and affected-party participation.
