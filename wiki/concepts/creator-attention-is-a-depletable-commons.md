# Creator attention is a depletable commons

## Definition

Creator attention is a depletable commons when an output such as code can be copied without limit but participation draws repeatedly on a small number of maintainers for review, support, moderation, reputation, and care.

## Distinctions and contested meanings

- The commons is not literally owned by users; the metaphor identifies a collective-action problem around finite human capacity.
- Participation can add capability or impose demand. Contributor count alone does not distinguish the two.
- Individual boundaries are necessary but insufficient when platforms and project governance create the overload.
- Reducing access may protect maintainers while limiting learning and inclusion.
