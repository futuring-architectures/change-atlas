## Curated excerpt

> *A lot of enterprise software is bad UI wrapped around a simple database operation. If an agent can just do the thing \- update the CRM, file the expense report, schedule the meeting \- without making you navigate seven tabs and three dropdown menus, that’s a genuine improvement. Some SaaS interfaces are, frankly, tax on human attention that exists only because we didn’t have a better way to talk to computers. Those interfaces should go away.*

## Atomic claims
