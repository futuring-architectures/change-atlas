## Curated excerpt

> *The default mental model for AI is still automation. People start with the existing workflow, ask which tasks agents can absorb, and then assign the leftovers to humans. That produces a deceptive view of the future firm: agents do the scalable work, humans do the irreducible work. But this is a reorganization of yesterday’s production logic. It assumes that the purpose of the organization stays fixed while only the distribution of tasks changes.*

## Atomic claims

### Claim 1

Starting AI adoption from existing tasks preserves yesterday's production logic even when tasks are redistributed between humans and agents.

- Classification: `interpretation`
- Scope: Organizational redesign around AI.
- Date relevance: Interpretation published 2026-03-29.
- Qualification: Incremental task automation can still create value or enable later redesign.

### Claim 2

The purpose and production logic of an organization should be reconsidered when AI changes its feasible capabilities.

- Classification: `normative_position`
- Scope: Strategic organizational transformation.
- Date relevance: Position published 2026-03-29.
- Qualification: Purpose changes require stakeholder legitimacy, not only technical feasibility.
