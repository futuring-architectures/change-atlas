## Curated excerpt

> *A loop is a small program you write that prompts the coding agent for you, reads what it produced, decides whether it is done, and if not, prompts it again. You stop being the thing inside the loop typing prompts. You become the author of the loop. The model becomes a subroutine \[…\] The job did not vanish. It moved up an altitude, from writing the code to writing the thing that writes the code.*

## Atomic claims

### Claim 1

An agent loop is a program that prompts a coding agent, evaluates its output, and repeats until a completion condition is met.

- Classification: `conceptual_claim`
- Scope: Definition of a coding-agent orchestration loop.
- Date relevance: Claim posted 2026-06-08.
- Qualification: Real loops also need termination, error handling, observability, state management, and safety constraints.

### Claim 2

In loop-based coding, human work moves from writing code or prompts inside the loop to authoring the loop that uses the model as a subroutine.

- Classification: `interpretation`
- Scope: Shift in developer role under agentic coding workflows.
- Date relevance: Claim posted 2026-06-08.
- Qualification: Humans may still inspect code, intervene in prompts, and retain accountability for outcomes.
