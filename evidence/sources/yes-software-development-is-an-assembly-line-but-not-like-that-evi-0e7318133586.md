## Curated excerpt

> *The manufactured widget of software is actually the discrete user interactions with those features and pieces of software, not the features themselves. The assembly line in software engineering isn’t, as many think, the engineers producing features. Rather, it’s software producing value-creating experiences for users.*

## Atomic claims

### Claim 1

The relevant manufactured unit in software is a discrete user interaction, not a software feature.

- Classification: `conceptual_claim`
- Scope: Value-production model for software products.
- Date relevance: Source published 2023-09-28.
- Qualification: Some software value arises at system, organizational, or deferred levels rather than in discrete interactions.

### Claim 2

Software engineering’s assembly line is software repeatedly producing valuable user experiences, not engineers producing features.

- Classification: `interpretation`
- Scope: Application of an industrial-production metaphor to software.
- Date relevance: Source published 2023-09-28.
- Qualification: The reframing highlights use value but may understate maintenance, reliability, and enabling platform work.
