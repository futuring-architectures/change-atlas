## Curated excerpt

> *The general-purpose computer eliminated the need to build a new physical device every time we need to perform a new computational task; we only need to write software. Machine learning eliminated the need to write new software; we only need to assemble a dataset and devise a learning algorithm suited to that data.*

## Atomic claims

### Claim 1

General-purpose computers removed the need to build a new physical device for each computational task by making tasks programmable in software.

- Classification: `conceptual_claim`
- Scope: Historical abstraction shift from dedicated machines to software.
- Date relevance: Source published 2024-10-24.
- Qualification: Specialized hardware remains useful or necessary for some tasks.

### Claim 2

Machine learning shifts task specification from writing explicit software toward assembling data and choosing a learning algorithm.

- Classification: `conceptual_claim`
- Scope: Machine learning as an abstraction layer over hand-coded task logic.
- Date relevance: Source published 2024-10-24.
- Qualification: Dataset creation and algorithm selection are themselves forms of specification and software engineering.
